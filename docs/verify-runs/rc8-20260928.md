## What the rc8 cut found, and fixed, before this run

1. **Staging had not received a migration since `0213a` (21 Sept).** `0213a`
   revoked a 7-argument `remember_conversation_state` that `0285` had already
   replaced on dev and staging, so it failed there. The runner stops at the
   first failure, so **0301 and 0302 (rc7) and 0303 to 0304 (rc8) never
   reached staging**. rc7's staging verify therefore ran without 0301 and
   0302. `0213a` now guards each statement on the signature existing. A fresh
   build is unchanged: 326 migrations rebuilt from empty locally.
2. **`verify-function-grants` could not read 0302's grants.** 0302 grants the
   caller-identity functions to `anon` on purpose (the Realtime fix), but from
   a loop. `0305` restates them as plain statements. It is a no-op on every
   database, and production has carried the same discrepancy since 25 Sept.
3. **`verify-bootstrap` could not see the `scan` world.** It is now declared in
   `use-env.mjs` with no ref (a throwaway project).
4. **The first full run was contaminated.** Something else changed staging
   during it (four "real org settings changed" reports from suites that never
   touch those settings), and three suites failed only because 0303 was
   missing. The run of record above had nothing else touching staging.
